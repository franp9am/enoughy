Enoughy is a daily screen-time limit for a child's Windows PC that the parent sets from this page.

  1. Create an account

    Register with a login and a password; this makes your family.

  2. Add a child

    Type the child's name; the page shows a setup code.

  3. Install on the child's computer

    On the child's PC, open enoughy.com/install, run the installer and type the setup code.

  4. Set the limit

    Back on your page, the child appears after the first sync; set the daily limit and the hours there.
