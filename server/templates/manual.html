Setting it up

  1. Create an accountRegister with a login and a password; this makes your family.
  2. Add a childOn your page, type the child's name (or nickname); it shows a setup code.
  3. Install on the child's computerOn the child's PC, open enoughy.com/install, run the installer and type the setup code. For a second child, run it again with that child's code and pick their account.
  4. Set the limitOnce you log in to enoughy.com, the child appears there after the first sync, and you set the daily limit and the hours.

These steps are for dashboard mode. For offline mode, step 3 alone is enough.

The two modes

  • Dashboard modeYou register an account, the child's computer reports to the server, and you see the time and change the rules on a web page. The server is enoughy.com by default. Power users can set up their own: it is open source, and the installer has a box for its address.
  • Offline modeNo server and no account. Nothing leaves the child's computer, and you grant extra time with codes. The rules and what the child sees are the same as in dashboard mode; what differs is in the section Offline mode.

The installer

Enoughy is supported on Windows 10 and 11. The installer runs on the child's computer and needs an administrator.

Windows may first show a blue box, "Windows protected your PC". It does that for any program that is new and not yet widely installed. Click "More info", check that the publisher is "Open Source Developer Peter Franek", and then click "Run anyway".

The installer asks four things.

  • Which account is the child'sThe limit is for this one Windows account; the other accounts on the computer stay free. An ordinary local account is enough, no Microsoft account is needed.
  • Who is the administratorA child who is an administrator can switch the limit off, so the installer offers to make the child's account a standard user. If it is the only account on the computer, the installer first creates an administrator account named parent, with a password you choose. Write it down: Windows asks for it whenever something needs an administrator.
  • The setup codeThe six digits from your page, good for an hour.
  • The time limitsMinutes a day, when the day starts and when the night starts. All of it can be changed later.

Then restart the computer. From then on Enoughy starts with Windows, and the box with the remaining time appears when the child logs in.

Running the installer again is safe: it shows the values in force and keeps the child's history.

The rules

  • Daily limitHow long the child may use the computer each day, anything from nothing to the whole day. Time counts while the child is logged in and the screen is unlocked, also when nobody touches the computer. A locked screen costs nothing, and neither does somebody else's account. A new day starts at midnight.
  • NightThe computer is usable from the time the day starts to the time the night starts, say 6:00 to 21:00. Five minutes before the night the child gets a message, and at the night the computer shuts down. A child who logs in during the night is shut down again within minutes. You can also have no night at all.
  • CarryoverTime not used today is added to tomorrow, up to a cap you choose. With a limit of one hour, a child who stays away for three days has four hours on the fourth. The cap can also be zero, for no carryover, or unlimited.
  • WeekdaysAny weekday can have its own limit, its own hours, or both: a longer Saturday, an earlier night before school.

The rules live on the child's computer, so they hold without internet too.

The dashboard

What you see after you log in. It refreshes itself every minute.

1 2 3 4 5 6
  1. A tab for each child. A child appears here once their computer has reported for the first time.
  2. Extra time for today.
  3. How much time the child has left today, and when their computer last reported. While the child is using it, that is every minute.
  4. The rules in force, as the child's computer itself reports them. "1h/d, 6:00-21:00, carryover ≤5h" is an hour a day, between 6:00 and 21:00, with at most five hours carried over. The word Settings opens the page that changes them.
  5. Screen time on each of the last seven days, today in black. Never what it was spent on.
  6. Your login. It opens your page: the children, their setup codes and "Log off".

Below the week, "Export" downloads all extra time and all screen time of the child as CSV files.

Settings

One page per child, behind the word "Settings" on the dashboard, with a box for each of the rules. The weekday exceptions fold open; a box left empty there means the general value.

"Save" sends the change to the child's computer at its next report. If the child is using it, the dashboard shows the new rules in force after a minute or two; otherwise when the computer is next turned on. Until then it says "new ones waiting". What it shows as in force is always what the computer itself reports.

The computer may also reject a change, for example a night that starts less than an hour after the day. The dashboard then says that the PC refused it, and the old rules stay.

Extra time

On the dashboard, type the minutes and press "Apply". The child's computer picks them up within a minute and tells the child. If the computer is off, the minutes wait under "Waiting for the next sync" and count for the day it is next turned on.

  • Taking time awayNegative minutes, say -30, take time away. At most what is left of that day; nothing reaches into tomorrow.
  • A longer eveningExtra minutes do not move the night. For a late evening, set a later night in Settings.
  • When the time is already upThe computer waits three minutes before it shuts down. Extra time that arrives in those minutes calls the shutdown off.

What the child sees

  • The box in the top right cornerThe time left today, like "1h 32m" or "45 min". Green, orange under fifteen minutes, red under five. At night it shows a moon. Clicks go through it to whatever is underneath, and Ctrl+Alt+H hides it and brings it back.
  • MessagesA small Windows message, in signs any child can read: "5 min" with a moon five minutes before the night, "+60 min" when extra time arrives, "0 min" when the time is up, and "Night time". There is no message before the time runs out; the box turning orange and red is the warning.
  • ShutdownThree minutes after "0 min" or "Night time", the computer closes everything and shuts down. Work that is not saved is lost, so teach the child to save when the box turns red.

The box is only a display. A child who hides or closes it still has the same limit.

Several children

  • Several children in a familyAdd each on your page. Each has their own setup code, rules and tab on the dashboard.
  • Several children on one computerEach needs their own Windows account. Run the installer once per child, with that child's code, and pick their account.
  • One child on several computersNot shared yet: every computer keeps its own limit. Add the child once per computer, under two names, say "Tom" and "Tom laptop".

A stronger lock

Enoughy holds as long as the child is a standard user, uses only their own account and does not know an administrator's password. Time on any other account is not counted, so every other account on the computer needs a password the child does not know.

For a child who knows computers, two more steps on the machine itself make it hard to get around:

  • A BIOS passwordSo the computer cannot be started from another disk.
  • BitLockerDisk encryption, so the disk cannot be read or changed in another computer. It also keeps the child out of Safe Mode, which starts Windows without most of its programs: with BitLocker on, Safe Mode asks for the recovery key. Keep that key from the child.

Updates and removal

  • UpdatesThe child's computer looks for a new version once a day and installs it by itself. For power users: an administrator can turn this off and on by writing manual or auto into this file: C:\ProgramData\Enoughy\UPDATE_MODE
  • Removing it from the computerUninstall enoughy in the Windows settings, under installed apps. That removes the program and the usage history on the computer, for every child on it. The Windows accounts stay as they are.
  • Removing a child from the server"Remove" on your page deletes the child and their usage history from enoughy.com.

Your account

  • Login and passwordThere is no email, so there is no password recovery. Write the password down. If it is lost all the same, write to me.
  • Staying logged inA browser stays logged in for 90 days, or until "Log off" on your page.
  • Two parentsFor now both use the same login.
  • What the server knowsFor each child and day: the time used and the time left, the extra time and codes, the rules in force, and when the computer shut down for the limit or the night. Nothing about what the child did with the time.

Offline mode

In the installer, tick "No server" instead of typing a setup code. Enoughy then needs no account: there is no dashboard, and the child's computer talks to nobody. The rules are the ones you type into the installer.

  • The codes pageAt its end the installer shows a QR code and an address. That is the page that makes extra-time codes for this child. The address ends with the child's name and a long key, like this one: https://enoughy.com/extra-time-codes#peter=5b1e9c04a7d263f80c4e1a9b7d3052c6 Scan it with your phone and bookmark it; the other parent can have the same bookmark. The page works inside your browser and sends nothing anywhere.
  • Keep the address secretThe long key in the address is what makes the codes valid. A child who sees the address, the QR code or the bookmark on your phone can make codes for themselves, so scan it when the child is not watching and never send it to them.
  • Extra timePick the minutes and the page shows a code, 60:fc95 in the picture. It works once, on the day it was made. The same minutes on the same day give the same code, so for a second one that day change the minutes.
  • No nightThe other kind of code keeps the computer up until midnight on that one day. The daily limit still counts.
  • Using a codeThe child opens "Extra time" from the Start menu, typing "extra" finds it, and enters the code. Within a minute a message confirms it.
  • Changing the rulesRun the installer again for the limit and the hours. For power users: to change the rules without a reinstall, or to add weekday exceptions and carryover, edit this file as an administrator: C:\ProgramData\Enoughy\data\<child>\settings.json The README describes it, and a change counts within a minute.
  • UpdatesThe computer stays as installed; to update, run a newer installer. Power users can turn the daily update on with the file under Updates. The computer then downloads new versions from GitHub once a day, and still sends nothing about the child.

To move to dashboard mode later, go through the four steps: the installer runs again, this time with a setup code.

Pricing

  • Offline modeFree forever.
  • Dashboard mode on enoughy.comFree forever for everyone who registers during the beta. The beta is running now.
  • Dashboard mode on your own serverFree forever; the server is open source.

Problems and contributing

  • Something does not workWrite to me. Say what you did, what you expected and what happened. Enoughy is made by one person in spare time, so an answer can take a few days.
  • Ideas and wishesThe same way. I read all of them and promise none.
  • For programmersThe code is on GitHub. Bugs can also go to the issues there, and pull requests are welcome; for a bigger change, write first.
